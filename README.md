## About

MinimalMc is a modern desktop launcher designed to make managing and launching Minecraft simple, clean and convenient.

## Features

- Minecraft instance management
- Version management
- Modrinth and CurseForge integrations
- Modpack import and export
- Java runtime management
- Backup and screenshot tools
- Skin management
- Modern desktop interface

## Platforms

- Windows
- Linux (`.deb`, `.rpm`, `.AppImage`, `.flatpak`)
